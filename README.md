# Willow & Wool Crochet Site

React single-page site for a crochet studio inspired by boutique fiber brands. Built with Vite and modern CSS.

## Getting started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the dev server:
   ```bash
   npm run dev
   ```
   The site will be available at the URL printed in the console.
3. Create a production build (optional):
   ```bash
   npm run build
   ```

## Customizing
- Update copy and structure in `src/App.jsx` to match your branding and product lineup.
- Adjust the palette and layout tokens in `src/index.css` for quick theming.
- Swap gradient placeholders with photography by replacing the `.gradient` divs with `<img>` tags.
